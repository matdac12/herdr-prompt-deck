A · Persistent bottom split pane — recommended

Always visible while you work; one keystroke to paste. Closest to your "bottom toolbar" idea.

  • Pastes into the pane you last focused (or a pinned target).
  • Costs vertical layout space in that tab.
  • Survives as long as the tab; can be toggled off.

B · Popup on a hotkey

Zero permanent layout cost. Opens centered, you pick, it closes.

  • Can't be "glanced at" while typing.
  • Great if the toolbar is used in short bursts.
  • Herdr popups capture Esc and all input.

C · Its own tab

Maximum room for file browsing / snippet editing. No space stolen from agents.

  • Switching tabs to paste breaks flow.
  • Best if the toolbar becomes a real editing surface.
  • Also a normal plugin pane under the hood.

What all three share

The toolbar is the same plugin either way — only its placement differs. So we can start with A and change to B/C later without a rewrite.

  • overlay, popup, split, tab, zoomed
  • Paste primitive: herdr pane send-text
