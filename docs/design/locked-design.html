How it behaves

  • Lives at the bottom of the tab; you click it or prefix ↑/↓ to focus it.
  • Pasting uses herdr pane send-text, so the agent's input receives the text but nothing is submitted.
  • esc closes the pane and refocuses the agent.
  • Works the same whether the neighbour is Claude Code, OpenCode, or Codex.

The three tools

  • Files — native OS dialog, inserts the absolute path (plus a small recent list).
  • Snippets — your saved prompts, fuzzy filter, n to create, e/d to edit/delete.
  • Editor — write anything and insert it.

Storage & sharing

Snippets live in a hand-editable file under the plugin's config dir, so you can also edit them outside Herdr.
